# Device test checklist

Target device: Android 9+, 2 GB RAM, arm64-v8a.

1. Airplane mode test.
2. 100 classroom sentences.
3. Fan/children noise.
4. Math numbers and operations.
5. Peak RAM.
6. ASR latency.
7. NMT latency.
8. First TTS audio latency.
9. 30 minute thermal run.
10. No ANR / crash / memory leak.
